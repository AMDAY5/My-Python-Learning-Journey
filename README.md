My-Python-Learning-Journey
这是我的 Python 学习仓库，用来存放平时练习写的小程序。目前有两个入门程序：一个计算 BMI，一个计算长方形的周长和面积。代码不难，但它们是我学 Python 写下的第一批完整程序，以后学到新内容会继续往这个仓库里加。



文件说明:

BMI计算.ipynb
输入身高、体重，计算并输出 BMI 值
长方形周长计算.ipynb
输入长、宽，输出长方形的周长和面积



代码说明:
BMI计算.ipynb
BMI 的计算公式是：体重 ÷ 身高的平方。程序先用 input() 接收键盘输入，用 float() 把输入的字符串转成小数，再按公式计算：
height = float(input("请输入身高（米）："))
weight = float(input("请输入体重（公斤）："))

bmi = weight / (height * height)

print("你的BMI是：", bmi)
长方形周长计算.ipynb
周长的公式是 (长 + 宽) × 2，面积是 长 × 宽：
length = float(input("请输入长："))
width = float(input("请输入宽："))

perimeter = (length + width) * 2
area = length * width

print("周长是：", perimeter)
print("面积是：", area)


两个程序都用到了 input() 和 float() 的配合，这是目前学到的让程序和人交互的基本方法。


学习心得与规划:
这次作业之前，我没认真看过别人的仓库。借这个机会在 GitHub 上搜了一些 Python 初学者项目，印象最深的有两点：一是做得好的项目 README 都很清楚，不看代码也能明白项目是干什么的、怎么运行；二是提交说明写得很具体，每一条都能看出那次改了什么。对照自己，我第一次上传时图省事，提交说明还留成了默认的 "Add files via upload"，后来重传时才改掉——这些细节平时觉得无所谓，真要给别人看项目时就成了减分项。
写 README 的过程也让我意识到，代码是写给机器的，README 是写给人的，能把一个项目介绍清楚，本身也是编程学习的一部分。
接下来的计划：每周往仓库里放一到两个练习，按主题建文件夹分类，README 里的文件说明跟着同步更新。等学到函数，我想把 BMI 程序重写成带函数的版本，放在同一个仓库里对比前后的差别。希望几个月后回头看，这个仓库能记下我从只会 print 到能写出完整小程序的过程。
